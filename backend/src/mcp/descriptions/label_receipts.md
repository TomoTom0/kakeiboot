レシートに色ラベルを付ける・外す。色は red / yellow / green / blue / purple の色名キーで指定する。

- receipt_ids に複数件（最大50）を渡せば一括で適用できる。add で付け、remove で外す（差分・冪等。再送しても同じ結果になる）。
- ユーザーがラベルのタイトル（例: 旅行）で言った場合は get_catalog の labels で色に解決してから渡す。
- 存在しない・他の家計簿の・削除済みのレシートはスキップし、結果の skipped に理由（not_found / deleted）ごと返す。全件スキップの場合はエラーになる。
- ラベルの付け外しでレシートの revision は変わらない。
- 下書き（draft）段階へのラベル指定はこの tool ではなく、作成時の payload.label_colors で行う（確定時にレシートへ引き継がれる）。
- タイトルの変更は web 画面の 設定 > ラベル で行う（この tool では変更できない）。
