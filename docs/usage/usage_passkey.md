# パスキー

パスキーは、kakeiboot へのログインに使う鍵です。顔認証や指紋認証で使います。

パスキーの管理は、右上のアカウントメニューから「設定」を開き、「認証」の「パスキー」で行います。

## 一覧の見方

| 表示 | 意味 |
|---|---|
| 同期済み | iCloud キーチェーンや Google パスワードマネージャーに保存されています |
| 端末内 | この端末の中にだけあります |
| 不明 | どちらか分かりません |

## パスキーを追加する

1. 「パスキー」の「+」を押します
2. 名前を入れます（任意）
3. 「追加」を押します
4. 画面の案内に従います

## 名前を変える

1. パスキーの行の鉛筆のボタンを押します
2. 名前を入れて保存のボタンを押します

## パスキーを削除する

1. パスキーの行のごみ箱のボタンを押します
2. 「削除する」を押します
3. 確認を求められたら、パスキーで認証します

最後の1本は削除できません。

## 機種変更をしたとき

同期済みのパスキーは、新しい端末でも同じアカウント（iCloud や Google）にログインすれば使えます。「パスキーでログイン」を押してください。

## パスキーをなくしたとき

同期のアカウントごと使えなくなったなど、ログインできないときは、運用者に直接連絡してください。

1. 運用者に連絡します
2. 運用者が本人確認をして、再登録用の URL を渡します
3. 届いた URL を開きます。有効期限が短いので、すぐに開いてください
4. 「パスキーの再登録」の画面で「パスキーを作成して登録」を押します

再登録について、次のことを確認してください。

- できるのはパスキーの追加だけです。表示名などは変わりません
- 登録が完了すると、ログイン中の他の端末はログアウトされます
- 前のパスキーは自動では消えません。不要なら、この画面から削除できます
- ChatGPT の接続はそのまま使えます
