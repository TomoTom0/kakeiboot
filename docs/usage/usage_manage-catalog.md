# カテゴリ・店・ラベルを管理する

右上のアカウントメニューから「設定」を開き、「データ」の「データの管理」から開きます。

ここで変えた内容は、その家計簿を使う全員に反映されます。権限が「閲覧のみ」の家計簿では変更できません。

## カテゴリ

「カテゴリ」には「品目カテゴリ」と「店カテゴリ」があります。上のタブで切り替えます。

カテゴリは、大分類とその下の小分類に分かれています。

### 追加する

- 大分類は、見出しの横の「+」を押して名前を入れ、「作成」を押します
- 小分類は、大分類の行の「+」を押して名前を入れ、「作成」を押します

### 名前や場所を変える

1. 行の「⋯」を押します
2. 「名前を変更」または「移動先を変更」を押します
3. 変更して「保存」を押します

「移動先を変更」は小分類でだけ使えます。

### 使わないカテゴリをしまう

カテゴリは削除できません。使わないものは「⋯」の「アーカイブする」を押すと、一覧や候補に出なくなります。

戻すときは「アーカイブ済みを表示」を押してから、「⋯」の「アーカイブから戻す」を押します。

## 店

### 名前を変える

1. 「店名で検索」で店を探します
2. 行の「⋯」から「編集」を押します
3. 店名と店カテゴリを変えて「保存」を押します

### 店を統合する

同じ店が別の名前で登録されているときは、1つにまとめられます。統合元のレシートは統合先に移り、統合元の名前は統合先の別名になります。

この操作は元に戻せません。

1. 画面の下の「店の統合（元に戻せない操作）」を開きます
2. 「統合元」と「統合先」を選びます
3. 「統合内容を確認」を押します
4. 内容を確認して「統合する」を押します

## ラベル

ラベルは家計簿ごとに5個あります。名前は任意で、名前がないラベルは色だけで表示されます。

1. 「ラベルの管理」を開きます
2. 名前を付けたいラベルの行を押します
3. 名前を入れて「保存」を押します

名前を空にして保存すると、名前なしに戻ります。

レシートにラベルを付ける方法は [レシートを修正する](usage_edit-receipt.md) を読んでください。
