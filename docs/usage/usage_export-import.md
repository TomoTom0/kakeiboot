# 書き出しと取り込み

家計簿1冊をファイルに書き出して、手元に保存できます。書き出したファイルは、新しい家計簿として取り込めます。

## 書き出す

1. 右上のアカウントメニューから「設定」を開きます
2. 「データ」の「データの書き出し・取り込み」を開きます
3. 「書き出し」で家計簿を選びます
4. 「書き出す」を押します
5. ダウンロードされたファイルを保存します

自分が参加している家計簿なら、権限にかかわらず書き出せます。

### 含まれないもの

次のものは書き出しに含まれません。

- 下書き
- 削除済みのレシート
- 家計簿のメンバー

レシート、明細、写真、カテゴリ、店、ラベルの名前は含まれます。

## 取り込む

取り込みは、常に新しい家計簿として追加します。今ある家計簿には影響しません。

1. 右上のアカウントメニューから「設定」を開きます
2. 「データ」の「取り込み」で、書き出したファイルを選びます
3. 「取り込む」を押します
4. 完了の表示を確認します

取り込んだ家計簿のオーナーはあなたになります。家計簿は右上のアカウントメニューから開けます。既定の家計簿は変わりません。

もとの家計簿のメンバーは引き継がれません。必要なら [家計簿を共有する](usage_share-ledger.md) の手順で共有してください。

## うまくいかないとき

「ファイル形式が正しくありません」と出たら、kakeiboot で書き出したファイルを選んでください。

「データが大きすぎて書き出せませんでした」「データが大きすぎます」と出たら、運用者に相談してください。
