# 支出を見る

記録したレシートは web 画面で見られます。下部のタブから「ホーム」「レシート」「カテゴリ」「店」を切り替えます。

## 画面の内容

| 画面 | 見られるもの |
|---|---|
| ホーム | 期間の合計、支出の推移、週ごとの支出、支出の内訳、最近のレシート |
| レシート | 期間の合計、支払方法、レシートの一覧 |
| カテゴリ | 期間の合計、支出の推移、カテゴリ別の金額 |
| 店 | 期間の合計、支出の推移、店別の金額 |

## 期間を切り替える

画面上部の期間のチップを押します。

1. 「週」「月」「年」「Custom」から選びます
2. 「週」「月」「年」は左右の矢印で前後に送ります
3. 「Custom」は開始日と終了日を入れて「表示」を押します

選んだ期間は、ほかの画面にも引き継がれます。

支出の推移の棒を押しても期間を移動できます。日ごとの棒を押すと、その日のレシート一覧が開きます。

## 詳しく見る

ランキングの行を押すと、その項目の詳細が開きます。

- カテゴリや店の詳細では、推移と、組み合わせごとのランキング、最近の明細が見られます
- 品目の詳細では、価格の履歴や店ごとの金額も見られます

レシートの詳細では、カテゴリや店の名前を押すと、その詳細へ移動します。

## レシートを見る

「レシート」の一覧で行を押すと、レシートの詳細が開きます。

- 上下にスクロールすると、前後のレシートを続けて見られます
- 左右の矢印でも前後へ移動できます
- 「一覧」で一覧へ戻ります

## レシートを絞り込む

1. 「レシート」の一覧で「絞り込み」を押します
2. 「店名」「品名」「カテゴリ」「支払方法」を入れます
3. 「適用」を押します

カテゴリは「食費」「食費/外食」「未分類」のように入れます。

## 検索する

1. 画面上部の虫眼鏡のチップを押します
2. 言葉を入れて「検索」を押します

検索結果は「レシート」と「品物」で切り替えます。「レシート」は品目名と店名を探します。「品物」は品目名だけを探します。

検索結果の上のチップで、「全期間」と選んでいる期間のどちらかを選べます。

## ラベルで絞り込む

1. 画面上部の虫眼鏡のチップを押します
2. 下の段のラベルを押します。複数選べます
3. やめるときは「解除」を押します

ラベルの絞り込みは、ほかの画面にも引き継がれます。

## 家計簿を切り替える

右上のアカウントメニューを開き、見たい家計簿を押します。詳しくは [家計簿を共有する](usage_share-ledger.md) を読んでください。

## 会話で聞く

ChatGPT の会話でも、「今月の食費はいくら？」のように支出を聞けます。
