# 家計簿を共有する

## 家計簿を切り替える

右上のアカウントメニューを開き、見たい家計簿を押します。

家計簿の切替は3か所に分かれています。

| 切り替えるもの | 操作する場所 |
|---|---|
| いま web 画面で見ている家計簿 | 右上のアカウントメニュー |
| web 画面を開いたときの家計簿 | 「設定」の「一般」にある「既定の家計簿にする」 |
| ChatGPT や Claude が記録する家計簿 | [接続中のアプリ](/apps)、または会話 |

web 画面を切り替えても、接続したアプリが記録する家計簿は変わりません。

## 家計簿の名前を変える

1. 右上のアカウントメニューから「設定」を開きます
2. 「一般」の「家計簿」で、行の「⋯」を押します
3. 「名前を変更」を押します
4. 名前を入れて「保存」を押します

名前は100文字までです。同じ名前の家計簿が自分の一覧にあるときは使えません。新しい名前は、その家計簿を使う全員に表示されます。

会話で「家計簿の名前を○○に変えて」と頼んでも変更できます。

## 権限

| 権限 | できること |
|---|---|
| オーナー | 記録・修正、共有 URL の発行 |
| 編集 | 記録・修正 |
| 閲覧のみ | 見ることと書き出し |

## 家計簿を共有する

家計簿を共有すると、相手はその家計簿のレシートをすべて見られます。

共有 URL で参加できるのは、kakeiboot のアカウントをまだ持っていない人です。URL を開くと、その人のアカウントが新しく作られます。

共有 URL を発行できるのはオーナーだけです。

1. 右上のアカウントメニューから「設定」を開きます
2. 「認証」の「家計簿を共有」で「+」を押します
3. 「家計簿」と「権限」を選びます
4. 「メモ」に、誰に渡すかを書きます。空欄なら発行日時になります
5. 「発行」を押します
6. 「URL をコピー」を押して、相手に送ります

- 権限はあとから変えられません
- URL は一度だけ表示されます。画面を離れる前にコピーしてください
- 期限は発行した行に表示されます
- メモは運用者も見られます

## 新しい人を kakeiboot に招待する

家計簿を共有せず、kakeiboot のアカウントだけを作ってもらうときは「登録の招待」を使います。相手には相手専用の家計簿が作られ、あなたの家計簿は見えません。

1. 右上のアカウントメニューから「設定」を開きます
2. 「認証」の「登録の招待」で「+」を押します
3. 「メモ」に、誰に渡すかを書きます。空欄なら発行日時になります
4. 「発行」を押します
5. 「URL をコピー」を押して、相手に送ります

URL は一度だけ表示されます。受け取った人の手順は [はじめに](usage_getting-started.md) にあります。
