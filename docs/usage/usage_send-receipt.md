# レシートを送る

レシートの記録は ChatGPT や Claude の会話で行います。写真を送ると、まず下書きが作られます。内容を確認して登録すると、家計簿に記録されます。

下書きの確認と登録は会話の中で行います。web 画面に下書きは表示されません。

## 写真を送る

1. 会話にレシートの写真を貼ります
2. 「これを登録して」のように送ります
3. 読み取った内容の確認が会話に表示されます

写真が kakeiboot に届かなかったときは、写真なしで記録されます。読み取った内容はそのまま確認して登録できます。

Claude では、会話に貼った写真は Claude が読み取るため kakeiboot に届かず、記録に写真は付きません。内容の確認と登録は同じように行えます。

## 内容を確認して登録する

会話に表示された店名、日付、明細、合計を確認します。

- 間違いがなければ「この内容で登録」を押します
- 直したいところは「店名を○○に直して」のように会話で伝えます

会話で「登録して」と頼んでも登録できます。

登録先の家計簿の名前は結果に表示されます。別の家計簿に記録したいときは、先に「家計簿を ○○ に切り替えて」と頼みます。

「内容が更新されています。」と出たら、内容を確認してもう一度登録してください。

## 複数枚をまとめて送る

複数のレシートをまとめて送ることもできます。

1. 会話に写真を貼って送ります
2. 「下書きの一括登録」に一覧が表示されます
3. 内容を確認して「すべて登録」を押します

直したいレシートがあるときは、登録の前に会話で伝えてください。

## 同じレシートかもしれないとき

「重複の可能性」と表示されたら、同じレシートがすでに記録されているかもしれません。表示があっても登録はできます。内容を確認して、登録するか破棄するかを決めてください。

## 下書きを破棄する

登録しない下書きは、会話で「この下書きを破棄して」と伝えます。

- 破棄した下書きは、30日以内なら会話で頼むと作り直せます。写真は戻りません
- 登録しないまま14日たった下書きは期限切れになります。こちらも30日以内なら作り直せます

## 未登録の下書きを探す

会話で「未承認の下書きを見せて」と頼むと一覧が表示されます。

## 登録したあとは

登録したレシートは web 画面で見られます。[支出を見る](usage_browse.md) を読んでください。内容を直すときは [レシートを修正する](usage_edit-receipt.md) を読んでください。
