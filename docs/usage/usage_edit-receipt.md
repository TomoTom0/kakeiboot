# レシートを修正する

登録したレシートは、web 画面でも会話でも直せます。この操作は、権限が「閲覧のみ」の家計簿ではできません。

## 内容を修正する

1. 「レシート」の一覧からレシートを開きます
2. 画面の下にある「内容を修正」を押します
3. 直したいところを入力します
4. 「保存」を押します

直せるのは次の項目です。

- 店名
- 購入日
- 時刻
- 支払方法
- 印字合計（円）
- メモ
- 明細の品名、金額、カテゴリ

明細のカテゴリは「大分類/小分類」の形で入れます。明細を消すには「削除」にチェックを入れます。増やすには「明細を追加」を押します。

保存しないで戻るには「修正をやめる」を押します。

合計の下に「明細合計」と「差額」が出ているときは、印字合計と明細の合計が合っていません。金額を確認してください。

## レシートを削除する

1. レシートを開いて「内容を修正」を押します
2. 画面の下の「このレシートを削除する」を開きます
3. 「削除の確認へ」を押します
4. 表示された内容を確認して「削除する」を押します

削除すると集計から外れます。90日以内なら復元できます。

## 削除したレシートを復元する

1. 「レシート」の一覧で「絞り込み」を押します
2. 「削除済みも一覧に表示」にチェックを入れて「適用」を押します
3. 「削除済み」と表示されたレシートを開きます
4. 「復元」を押します

会話で「このレシートを復元して」と頼んでも復元できます。

## ラベルを付ける・外す

ラベルは、レシートに付ける色の目印です。旅行や立替など、自由な分類に使えます。

1. レシートを開きます
2. 店名の下の小さなラベルのボタンを押します
3. 色を押します。もう一度押すと外れます

ラベルの名前は [カテゴリ・店・ラベルを管理する](usage_manage-catalog.md) で付けられます。

## 写真が表示されないとき

「画像の表示期限が切れました。」と出たら、「再取得」を押します。
