# はじめに

kakeiboot は、レシートの写真を ChatGPT に送るだけで記録できる家計簿です。記録した内容は、この web 画面でいつでも見られます。

使い方の流れは次のとおりです。

1. 届いた URL からアカウントを登録する
2. ChatGPT に接続する（最初に一度だけ）
3. ChatGPT にレシートの写真を送り、内容を確認して登録する
4. web 画面で支出を見る

## アカウントを登録する

kakeiboot の登録は招待制です。すでに使っている人から URL を受け取って始めます。

1. 届いた URL を開きます
2. 「表示名」を入力します（100文字まで）
3. 「このパスキーの名前」を入力します（任意。例: iPhone）
4. 「パスキーを作成して登録」を押します
5. 顔認証や指紋認証など、スマホの画面の案内に従います

パスキーは、パスワードの代わりに顔認証や指紋認証でログインするしくみです。パスワードを覚える必要はありません。

登録すると、あなた専用の家計簿が作られます。

### 家計簿の共有を受けた場合

共有の URL から登録すると、あなた専用の家計簿に加えて、共有された家計簿にも参加します。画面に家計簿の名前と権限が表示されるので確認してください。

「(家計簿の名前)を web 画面の既定の家計簿にする」にチェックを入れたままにすると、web 画面を開いたときにその家計簿が表示されます。

### 登録できないとき

「登録用 URL が無効か、期限切れか、使用済みです。」と出たら、URL を送ってくれた人に新しい URL を依頼してください。URL は1回だけ使え、期限があります。

## ログインする

1. web 画面を開きます
2. 「パスキーでログイン」を押します
3. 顔認証や指紋認証を行います

ログアウトは、右上のアカウントメニューの「ログアウト」から行います。

## 既定の家計簿を変える

既定の家計簿は、web 画面を開いたときに表示される家計簿です。次に ChatGPT を接続するときの最初の家計簿にもなります。

1. 右上のアカウントメニューから「設定」を開きます
2. 「一般」の「家計簿」で、既定にしたい家計簿の行の「⋯」を押します
3. 「既定の家計簿にする」を押します
