# v0.1.0

changelog 導入時点で実装済みの機能を、初版としてまとめたものです。導入以前の変更については、個別の日付や版の切り分けを記録していなかったため、ここでは行いません。

## New Features

- レシートの記録: ChatGPT 等の MCP クライアントに接続し、レシートの写真を送ると店名・日付・品目・金額が読み取られて下書きになり、会話の中で確認・修正して登録できる。複数枚の写真にも対応する
- 支出の閲覧: ホーム・レシート・カテゴリ・店の画面で支出を見られる。期間の切替、詳細の表示、絞り込み、検索に対応する
- レシートの修正: 登録済みレシートの修正・削除・復元と、ラベルの付け外しができる
- カテゴリ・店・ラベルの管理: 名前の管理、アーカイブ、店の統合ができる
- 家計簿の共有: 家計簿の切替と名前の変更、共有 URL による共有、登録の招待ができる
- 書き出しと取り込み: 家計簿単位でデータを書き出し、取り込める
- パスキー認証: パスキーの追加・名前の変更・削除、機種変更への対応、紛失時は運用者が発行する再登録 URL で再登録できる
- 使い方の提供: 利用者向けの使い方を web 画面の使い方ページに表示する（本文の正本は `docs/usage/`）
